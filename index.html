✨ Features

Everything you need to track your portfolio

From exchange balances to broker positions and on-chain wallets, Track3 brings your sources and analysis together on desktop and iOS.

🔒

Local portfolio storage

Portfolio records live in local SQLite. Sensitive configuration and chat content are encrypted before storage.

📈

Rich Analytics & Charts

Explore allocation, P&L, top movers, wallet breakdowns, historical trends, and period comparisons.

🔗

Exchanges, Brokers & Wallets

Connect centralized exchanges with read-only API keys, import Interactive Brokers positions, and track on-chain wallets in one place.

💰

Profit & Loss Tracking

Review realized and unrealized P&L with FIFO, LIFO, HIFO, and average cost basis, plus tax-year CSV and JSON reports.

📦

Backup and encrypted sync

Import and export files, use incremental monthly backup folders, or configure passphrase-encrypted sync with your own S3 storage.

⛓

No Wallet Signature Required

Track3 only reads public on-chain data and exchange balances. It never asks you to sign a transaction or grant fund access.

🎯

Goals and alerts

Set portfolio or asset targets, watch price moves and allocation drift, and review alert history. iOS can deliver local notifications.

⚖

Rebalancing

Set target weights and trade constraints, then review suggested changes and export them to CSV.

🔍

Insights and source status

See portfolio insights and per-source refresh status, including errors and retry controls.

🔐

Security and language

Rotate the local encryption key and use Track3 in English or Simplified Chinese.

⚡ Track3 Pro

More chains, fresher portfolio data

Pro adds hosted refresh and price endpoints for wallets that need broader chain coverage. Portfolio history stays in the local app database; sensitive configuration is encrypted before storage.

85+ EVM chains

Refresh ERC20 assets across 85+ supported EVM networks, including Ethereum, BNB Chain, Polygon, Arbitrum, Avalanche, Optimism, Base, and more.

TRON / TRC20 assets

Add TRON wallets and refresh TRC20 balances through the Pro API, including token values when price data is available.

Per-exchange and per-wallet views

Inspect assets for each connected exchange account and wallet separately, so you can see exactly where each balance is held.

Real-time portfolio value

Unlock the fast top-bar view that compares live portfolio value against your last saved refresh.

Real-time prices for all assets

Fetch live prices across all tracked assets during refreshes, so valuations stay current without waiting for the free local price path.
