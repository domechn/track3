If checkout issued a license key, enter it in the Track3 desktop app to activate Pro.

  1. Open the Track3 desktop app.
  2. Open Settings → System → Pro license.
  3. Enter your license key. If Pro does not appear, check the key and try again.

To use Pro on another desktop device, enter your license key in Settings → System → Pro license. You can use it on up to 3 devices. Keep it safe: anyone with the key can use it.

If you have a subscription, you can manage or cancel it from System Info in the desktop app.

Trouble? Open an issue and include the email on your Stripe receipt.
