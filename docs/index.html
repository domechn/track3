Track3 Docs · Exchanges

Connect an exchange safely

Create a read-only exchange API key so Track3 can read your balances. Give the key only the access it needs.

Last checked: 2026-10-29

Choose read-only access

Track3 reads exchange balances. Select Read or Enable Reading, according to the exchange. Never select Trade, Withdraw, or Transfer permissions for a Track3 key.

Check the permissions yourself. Track3 cannot currently detect whether a key has trading or withdrawal access.

Where your key lives

Track3 sends exchange requests directly from your device to the exchange, with no Track3 server in between. Exchange keys are stored locally.

If you use optional end-to-end-encrypted multi-device sync, the sync snapshot includes exchange keys only when you turn on the switch for exchange API keys and wallet addresses. Pro wallet balance queries for ERC20 and TRON are separate and do not use exchange keys.

Consider an IP allowlist

An IP allowlist limits where a key can be used. It can help on a device with a stable public IP. Home IPs can change, and a VPN or proxy changes the IP the exchange sees. Update the allowlist if your connection changes.

On iPhone and iPad, switching between Wi-Fi and cellular makes an IP allowlist impractical. A read-only key without IP binding is the practical choice on mobile. Keep every other permission off.

If a key leaks

Delete the key on the exchange. Then create a new read-only key if you still want to connect the exchange to Track3.

Known limits

  • Binance.US accounts are not supported. Track3 uses the Binance global API domains.
  • OKX accounts registered in the US, AU, or EU are likely not supported; this has not been tested. Those accounts require regional API domains, while Track3 uses the global OKX domain.
