## Remaining differences

Capture: `/tmp/fidelity/settings-b/ai.png` (full page: `ai-long.png`). Design and app were compared side by side at 390 × 844 CSS px. Remaining differences are listed below.

- The source shows a partly revealed sample API key. The app uses a password input that masks the whole key, preserving secret handling.
- The source model is a selector with a chevron. The app keeps an editable model field with suggestions so custom provider models remain usable; the control shape differs.
- The model probe returns success/failure but no token usage. The app measures the elapsed time and displays the model and test time; the source’s 38-token count cannot be verified.
- Inputs now use 16px text on iPhone to avoid focus zoom. The model field has the source chevron and the probe result has the matching status icon. Small field spacing and the live probe wording still differ.
