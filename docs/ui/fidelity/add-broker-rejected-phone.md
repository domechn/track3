## Remaining differences

- The design shows a remote token rejection during Save and test. Track3 checks only that the IBKR token and Flex Query ID are present at save time; remote authorization happens when data is fetched. A save-time “IBKR rejected this token” message would be fabricated. The capture shows the real duplicate source error for the entered Flex Query ID instead.
- The source card uses a shorter sample masked token and a different Flex guide icon.
