## Remaining differences

- Binance is the product's default exchange. The capture selects Bitget to show the design state without changing that default.
- Exchange names, help text, and icon strokes have small rasterization differences despite matching the source's Public Sans size, weight, and geometry. The source picker tiles are static `div` elements; Track3 keeps them as keyboard-accessible buttons, so the product cannot adopt the source semantics just to erase this residual.
