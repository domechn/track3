## Remaining differences

- The sheet, title, table, quota box, and footer now share the source page's measured bounds. The app keeps the real source balances, quota read, and refresh action; the source's per-source refresh time is unavailable from the shared snapshot behind the sheet.
- The quota glyph, table text rasterization, and footer icon strokes differ slightly.
- The design uses separate refresh times per source. The existing snapshot stores one shared refresh time, so the app shows the available snapshot time and a dash for paused Kraken.
- The underlying source row controls sit lower than the source and the read-only banner is displaced toward the bottom; source logo artwork and row icon strokes also differ.
