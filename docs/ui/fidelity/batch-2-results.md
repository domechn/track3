The exchange picker is 3.554%; its nonsemantic source tiles are keyboard-accessible buttons in Track3, and the remaining text rasterization is recorded in its page note. Ratios are evaluated alongside behaviour, accessibility, guard, golden, and persisted-format checks.

The current product cannot supply per-source refresh times, custom-source enabled flags, assistant tool activity after persistence, an import settings-conflict preview, local encryption recovery keys, or iOS in-app updates without product and storage changes outside this task. No real AWS Console session was generated.
