# Assistant harness audit

Scope: `src/middlelayers/ai/**`, `src/components/assistant/**`, and `src/components/settings/assistant.tsx`. References identify the location of the issue in the original code, before this refactor. P0 risks data loss or privacy; P1 breaks a normal chat; P2 is a reliability or cost issue.

| Priority | Finding and evidence | Status |
| --- | --- | --- |
| P0 | `src/middlelayers/ai/provider.ts:210-214,269-317`: HTTP requests ignored Stop and had no timeout; a broken stream could still emit a partial tool call. | **Fixed** — abort covers the request; the first response has a 180 second timeout, then a 60 second idle timeout resets on each streamed chunk. Broken streams discard tool calls. |
| P0 | `src/middlelayers/ai/sessions.ts:256-264`: append treated malformed encrypted content as an empty conversation and overwrote it. | **Fixed** — invalid payloads reject append and preserve the file. Session loads also validate the message list. |
| P0 | `src/components/assistant/chat-composer.tsx:21-39`: pasted images were written as plaintext under app data and never deleted. | **Fixed** — images stay in memory, object URLs are released, and the old attachment directory is removed once when the composer first opens. |
| P1 | `src/components/assistant/use-chat.ts:463-482,590-598`: two sends in one render could both start; an older `finally` could clear the newer controller. Stop could leave the guard set while the composer appeared ready. | **Fixed** — a synchronous in-flight guard and request-owned cleanup serialize sends and permit a new send immediately after Stop. |
| P1 | `src/components/assistant/use-chat.ts:93-103,482-487,531-588`: history was trimmed by message count, allowing long earlier turns and tool summaries to grow without a character limit. | **Fixed** — earlier turns and tool output now have character budgets; shortened history begins with a user turn. Final rounds disable further tool calls when over budget. The current user message is preserved intact; see the strict token-budget deferral below. |
| P1 | `src/middlelayers/ai/tools.ts:41-55`, `src/middlelayers/ai/provider.ts:159-165`, `src/middlelayers/ai/orchestrator/analyzer.ts:113-132`: malformed or wrong-type tool arguments reached skills, and malformed plan arguments could turn into an unfiltered request. | **Fixed** — the shared dispatch validates advertised argument types, required fields, enums, and size. Optional `null` values and unknown keys are omitted; invalid JSON receives a clear error. Malformed plan arguments fall back to the normal tool loop. Errors return to the model as tool results. |
| P1 | `src/middlelayers/ai/orchestrator/analyzer.ts:113-145`, `src/middlelayers/ai/orchestrator/scheduler.ts:174-197`: duplicate IDs, missing dependencies, and cycles could corrupt scheduling or overflow depth recursion; failed prerequisites did not block dependents. | **Fixed** — model plans are bounded and dependency-checked; dependents of failed tasks emit an error without running. |
| P1 | `src/middlelayers/ai/orchestrator/scheduler.ts:53-68`, `src/components/assistant/use-chat.ts:331-332`: planned tools had unlimited concurrency while direct tool calls were serial. | **Fixed** — both paths execute up to four independent calls at a time. |
| P1 | `src/middlelayers/ai/orchestrator/llm.ts:52-83`: timeout cleanup only happened after a successful fetch, and Stop did not reach planning, synthesis, or refinement. | **Fixed** — the nonstreaming helper clears its timer in `finally`, and the chat signal reaches every orchestrator call. |
| P1 | `src/components/assistant/chat-page.tsx:200-268`, `src/middlelayers/ai/sessions.ts:168-217`: overlapping completions could create multiple new sessions or race metadata writes; title generation delayed navigation and save errors were only logged. | **Fixed** — concurrent completions share a session ID, and returning to a fresh chat clears it so the next conversation creates another session. File and metadata writes use the encryption gate, title generation runs after navigation, and save failures appear in the chat. The chat skips a reload only when its first session ID is assigned; revisiting it after another session loads its history. |
| P1 | `src/components/assistant/use-chat.ts:124-179,267-345`: session reloads could replace a live answer; aborted or unmounted streams could still write UI state. | **Fixed** — active responses ignore stale reloads, Stop and session switches abort requests, and unmounted streams finish for background persistence without writing React state. Unmount clears the sidebar processing indicator. |
| P1 | `src/components/assistant/chat-page.tsx:165-174`: a decrypt failure was shown as an empty session, hiding the reason and allowing a misleading new send. | **Fixed** — the conversation is blocked with a visible localized load error. |
| P1 | `src/components/assistant/chat-page.tsx:154-184`: the composer was available before an existing session's messages had loaded, so a send could miss history and then be replaced by the late load. | **Fixed** — sending waits for the session load to finish. |
| P1 | `src/middlelayers/ai/orchestrator/index.ts:79-85`: failed planned tools were omitted from synthesis, so a partial answer could sound complete. | **Fixed** — synthesis receives failed tasks and their error descriptions. |
| P1 | `src/middlelayers/ai/sessions.ts:220-231`: deletion discarded the DB row even if encrypted-file removal failed. | **Fixed** — file removal must succeed before row deletion; a failure stays in the chat UI with a localized error. |
| P1 | `src/middlelayers/ai/skills/functions/trace.ts:22-36`, `src/middlelayers/ai/tools.ts:54-60`: developer traces printed model arguments, result text, and raw errors, which may contain private data. | **Fixed** — tracing logs operation names only; the unused error trace and its calls are removed. |
| P2 | `src/middlelayers/ai/provider.ts:106-139`: SSE framing missed CRLF and multiline data and silently discarded malformed JSON. | **Fixed** — records parse with either line ending. Non-JSON padding is skipped if usable content follows; a stream with only malformed data reports an error. Broken streams discard partial tool calls. |
| P2 | `src/middlelayers/ai/prompt.ts:21-34`, `src/middlelayers/ai/orchestrator/analyzer.ts:69-76`, `src/middlelayers/ai/orchestrator/synthesizer.ts:62-82`, `src/middlelayers/ai/orchestrator/optimizer.ts:33-61`: user and tool data shared a system message with instructions, allowing lower-trust text to pose as higher-trust instructions. | **Fixed** — system messages contain rules; conversation and tool data use separate user messages with explicit untrusted-data instructions. This reduces prompt-injection risk but cannot guarantee model obedience. |
| P2 | `src/middlelayers/ai/sessions.ts:32-35`: unsubscribing left empty listener sets in the module map. | **Fixed** — empty sets are removed. |
| P2 | `src/components/settings/assistant.tsx:38-66,341`, `src/middlelayers/ai/provider.ts:69-77`: advanced options accepted invalid value types, one warning was English-only, and `extraBody` could replace protocol fields. | **Fixed** — value shapes are checked, new UI copy exists in English and Chinese, and protocol fields are protected. |
| P2 | `src/middlelayers/ai/sessions.ts:309-363`: title generation could wait forever. | **Fixed** — it times out after 10 seconds and falls back to a preview. |
| P2 | `src/middlelayers/ai/prompt.ts:19`, `src/middlelayers/ai/orchestrator/analyzer.ts:29`: UTC dates could be one day ahead of the user's local date. | **Fixed** — both prompts use the local calendar day. |
| P2 | `src/middlelayers/ai/provider.ts:327-333`, `src/middlelayers/ai/orchestrator/llm.ts:86-92`: endpoint error bodies could become huge chat messages. | **Fixed** — displayed error bodies are limited to 1,000 characters. |
| P2 | `src/middlelayers/ai/orchestrator/llm.ts:74-77`: a 200 response with non-text completion content was marked successful and could crash refinement. | **Fixed** — non-text content returns a structured error. |
| P2 | `src/components/assistant/use-chat-sessions.ts:21-31`: a stale list refresh could remove a newly created session from the sidebar. | **Fixed** — stale responses no longer replace newer local changes. |
| P2 | `src/components/assistant/quick-actions.tsx:12-19`, `src/components/assistant/use-chat.ts:412-427`: quick-action prompts and progress text stayed in English when the UI was Chinese. | **Fixed** — prompts and progress text use matching English and Chinese locale keys. |
| P2 | `src/components/assistant/use-chat.ts:489-517`: simple questions still pay for a separate analyzer request. | **Deferred** — a keyword shortcut would misroute follow-ups; a combined planning and answer request needs a compatible protocol design across providers. |
| P2 | `src/middlelayers/ai/skills/functions/prices.ts:16-53`, `src/middlelayers/ai/skills/market-price.ts:40`: underlying price fetches cannot be canceled and report many failures as empty results. | **Deferred** — Rust `invoke` and the stock price helper need cancellation and structured error support first. |
| P2 | `src/middlelayers/ai/sessions.ts:238-280`: a crash after writing a valid `.tmp` but before overwriting an existing main file can lose the last append. | **Deferred** — safe atomic replacement across Tauri's supported file systems requires a platform-specific recovery design. Existing invalid files are now preserved rather than overwritten. |
| P2 | `src/components/assistant/chat-composer.tsx:107-161`, `src/components/assistant/use-chat.ts:71-103`: a single very large user message or inline image can still exceed a provider's context window. | **Deferred** — the current message is kept intact to avoid silently changing a request. Provider-specific token counting and proper multimodal image parts are needed for a strict limit. |
| P2 | `src/middlelayers/ai/provider.ts:191-325`, `src/middlelayers/ai/orchestrator/llm.ts:13-91`: transient HTTP failures have no automatic retry. | **Deferred** — blind retries can duplicate billable completions and replay tool decisions; a retry policy needs explicit error classification and backoff. |

Verification: `corepack yarn tsc --noEmit` and `corepack yarn vitest run` pass on this worktree.
