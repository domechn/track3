# Responsive iPad browser captures

These screenshots come from Chromium mobile Playwright with fixture portfolio
data and mocked Tauri IPC. They show the responsive web UI; they do not
verify a native iPad build or WebKit rendering.

`mini-portrait-overview.png` is 744 × 1133 CSS px. The `pro-landscape-*`
captures are 1376 × 1032 CSS px. Light and dark Overview, History detail,
Settings, Analytics charts, and Assistant are represented here. The full
viewport and theme matrix is attached to the iOS workflow as the
`ios-browser-screenshots` artifact.
