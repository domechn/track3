# Responsive iPad browser captures

These screenshots come from Chromium mobile Playwright with fixture portfolio
data and mocked Tauri IPC. They show the responsive web UI; they do not
verify a native iPad build or WebKit rendering.

`mini-portrait-overview.png` is 744 × 1133 CSS px. The `pro-landscape-*`
captures are 1376 × 1032 CSS px. Light and dark Overview, History detail,
Settings, Analytics charts, and Assistant are represented here. The full
viewport and theme matrix is attached to the iOS workflow as the
`ios-browser-screenshots` artifact.

The `pro-portrait-*` captures are 1032 × 1376 CSS px and show Settings and
Assistant after the nested split layout fix. `ipad-11-portrait-wallets.png`
is an 834 px wide full-page capture showing the Volatility sort control.
`mini-portrait-analytics-profit.png` shows the centered Returns sheet at
744 × 1133 CSS px. The Settings and Assistant captures show the two-pane
layouts, and the History capture shows the shorter wide-window rows.
`ipad-11-landscape-history-scrolled-detail.png` shows snapshot 18 with its
detail still visible after scrolling the list.
