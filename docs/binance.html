Create a read-only Binance API key

Use a System-generated key with reading access to connect Binance balances to Track3.

Last checked: 2026-10-29

Before you start

Binance requires identity verification, two-factor authentication, and a deposit of any amount to your Spot wallet to activate the account before you create an API key.

Choose System-generated, the HMAC key type. Track3 signs Binance requests with HMAC-SHA256. Self-generated Ed25519 or RSA keys are not the key type Track3 uses.

Create the key

  1. Log in on the Binance website. Open your profile icon → Account → API Management → Create API.
  2. Select System-generated, enter a label for the key, and complete the requested two-factor or passkey verification.
  3. When the key is created, review its permissions before adding it to Track3.

In the Binance app's Pro version, the documented path is More → Other → API Management → Create API.

Permissions: tick this, do not tick that

Tick: Enable Reading.

Do not tick: trading, withdrawals, internal transfer, or universal transfer permissions.

Track3 reads spot account, funding wallet, Simple Earn flexible and locked positions, cross-margin account, and USDⓈ-M futures balance. We have not verified the exact permission each section needs, including whether read-only futures or margin balances need their separate permission flags. Start with Enable Reading alone and check Source status after a refresh if a section is missing.

IP restriction (optional)

A System-generated key with unrestricted IP access can have only Enable Reading. If you have a stable public IP, you can restrict the key to it. Home IPs change, and a VPN or proxy changes the IP Binance sees, so an outdated allowlist can stop requests.

On iPhone and iPad, switching between Wi-Fi and cellular makes an IP allowlist impractical. A read-only key without IP binding is the practical choice on mobile.

Copy the values

Keep the API key and Secret key from your new System-generated key together until you enter them in Track3. Treat the Secret key as sensitive. Binance keys do not need a passphrase in Track3. We have not verified whether the Secret key is shown again after creation.

Enter them in Track3

These steps use the Track3 desktop app.

  1. Open Settings → Configuration → Exchanges → Add Exchange Configuration.
  2. Under Type, use Select CEX and choose Binance.
  3. Paste the API key into Api Key and the Secret key into Api Secret. Then select Save changes.

Troubleshooting

  • Wrong permission: Confirm Enable Reading is on and trading, withdrawal, and transfer permissions are off. Track3 cannot check the key's permissions for you.
  • A balance section is missing: After a refresh, the Source status dialog names the section. We have not verified the exact Binance permission each section needs.
  • IP not allowed: Check that the allowed IP matches the public IP Binance sees, especially after a home IP, VPN, or proxy change.
  • Account type: Binance.US accounts are not supported. We have not verified how sub-accounts or unified account setups affect balance visibility.
  • Clock skew: We have not verified Binance clock-skew behavior for this guide.

Use the official Binance key guide and API permission reference as the source of truth if the exchange screens change.
